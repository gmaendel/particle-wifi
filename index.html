Particle Wi-Fi

Support

Set up Wi-Fi on Particle devices from your phone, over Bluetooth.

What the app does

Particle Wi-Fi finds nearby Particle devices that are in Listening Mode, opens an encrypted Bluetooth session with the device using the setup code on its sticker, and sends it the Wi-Fi network you choose. When setup finishes, the device restarts and joins your network.

What you need

  • A Particle Wi-Fi device that supports Bluetooth setup, such as a Photon 2.
  • The device's setup code: the QR code on its sticker, or the code printed beside it.
  • An iPhone, iPad, or Android phone with Bluetooth turned on.
  • The name and password of a Wi-Fi network the device can reach.

Setting up a device

  1. Put the device in Listening Mode: hold its MODE button until the status light blinks dark blue.
  2. Open Particle Wi-Fi and tap the device when it appears in the list.
  3. Scan the code on the device's sticker, or type it in.
  4. Pick your Wi-Fi network from the list the device finds, enter the password, and send it.
  5. Wait for the device to restart and connect.

Troubleshooting

  • The device doesn't appear: check that its light is blinking dark blue and that Bluetooth is on and allowed for the app. Move the phone closer and tap Scan again.
  • The setup code isn't accepted: make sure you scanned the sticker of the same device. If the device was set up before, the app may ask for the code again; that's expected.
  • The setup service isn't found: turn the device off and on, put it back in Listening Mode, and try again.
  • The device doesn't join Wi-Fi: check the password, and that the network is 2.4 GHz or another band your device supports.
