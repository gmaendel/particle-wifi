# Particle Wi-Fi website

Public pages for the Particle Wi-Fi app (Android and Apple), served by GitHub Pages from the `main` branch.

- Privacy policy: https://gmaendel.github.io/particle-wifi/privacy/ (source: `privacy/index.html`)

The privacy policy URL is set in Google Play Console (App content → Privacy policy). Keep that page at the same path, and update its effective date when the policy changes.
